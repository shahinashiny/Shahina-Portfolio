# University Student and Staff Attendance Intelligence Platform

**Academic project period:** February 2026 – July 2026.

A data engineering and attendance-risk project for a university attendance portal. The resume describes a pipeline using Python, SQL, Apache Airflow, and REST APIs to combine attendance, schedules, course, and faculty data with validation checks.

The project workflows use Pandas, scikit-learn, and XGBoost to analyze recurring absences and generate risk indicators for students and classes requiring review. Curated datasets are created in AWS S3 and PostgreSQL, with Spark transformations and Power BI dashboards for attendance trends, engagement, and daily and weekly KPIs. Docker, Git, MLflow, and Airflow are integrated for version control, model tracking, scheduling, logging, and automated data refreshes.

**Data notice:** The runnable portfolio implementation in this repository uses generated synthetic records. No real student, employee, or institutional data is included. Model metrics, where generated by the demo, are synthetic-data demonstration results and are not claims about the academic project or a live university system.

## Technical scope

- **Ingestion and validation:** Python, SQL, Apache Airflow, REST APIs.
- **Attendance-risk workflow:** Pandas, scikit-learn, XGBoost.
- **Curated data and reporting:** AWS S3, PostgreSQL, Spark, Power BI.
- **Pipeline and model workflows:** Docker, Git, MLflow, Apache Airflow.
